### DoH

DoH means DNS over HTTPS. It sends DNS queries through HTTPS, so the query content is protected by encryption and can look similar to ordinary HTTPS traffic.

### private resolver


A private resolver means a resolver that is not a well-known public DoH service. In my proposal, it is important because an address-list detector may not know it in advance.

### short-lived DoH flow

A short-lived DoH flow is a DoH connection with only a short duration or a small number of packets. It is difficult because the classifier has very limited information from the flow itself.

### observation unit

The observation unit means what input the detector uses to make a decision. In my proposal, I compare one isolated flow with a host-level time window.

### host-level time window

A host-level time window means a short period of traffic from the same monitored host around the candidate flow. It can include timing gaps, repeated short flows, and nearby encrypted traffic patterns.

### metadata

Metadata means external traffic information, such as packet size, direction, timing, duration, and flow counts. It does not include the communication content.

### resolver identity

Resolver identity means information that can directly identify the DNS resolver, such as its IP address. If a detector depends on this, it may fail for unseen private resolvers.

### single-flow baseline

A single-flow baseline is a detector that judges each flow only from its own metadata. I use it as the main comparison target for the host-level model.

### host-level model

A host-level model uses information from the candidate flow and nearby traffic from the same host. It tests whether surrounding behavior helps when the candidate flow is too short.

### feature ablation

Feature ablation means removing one group of features at a time and checking how the result changes. It helps identify which context information is actually useful.

### false positive

A false positive means ordinary HTTPS traffic is incorrectly detected as DoH. This matters because a detector with many false alarms is not practical.

### detection latency

Detection latency means how long the system must wait before making a decision. A longer window may improve context, but it can also delay detection.

### TLS

TLS means Transport Layer Security. It encrypts application payloads, so in my undergraduate thesis I used external traffic patterns instead of reading the content.

### TLS encrypted traffic classification

TLS encrypted traffic classification means identifying the application category of encrypted TLS traffic from observable metadata, such as packet-length sequences.

### flow

A flow is a group of packets that belong to the same communication connection. In my undergraduate thesis, each TLS flow was treated as one traffic sample.

### five-tuple

A five-tuple means source IP, destination IP, source port, destination port, and transport protocol. It is commonly used to identify a network flow.

### packet trace

A packet trace is a recorded sequence of packets captured from network traffic. It can be converted into flow records and metadata features.

### packet-length sequence

A packet-length sequence is the ordered list of packet sizes in a flow. I used it because payload contents are hidden by TLS, but packet sizes are still observable.

### TCP-level perturbation

A TCP-level perturbation means a change caused by transport-layer behavior, such as retransmission, sequence shift, or packet aggregation. It can change the packet-length sequence without changing the application.

### retransmission

Retransmission means sending a packet again when the original packet may have been lost. It can repeat packet lengths and change the observed sequence.

### sequence shift

Sequence shift means that the visible packet sequence is shifted or misaligned because of transport-level behavior. It can make the same application traffic look different.

### packet aggregation

Packet aggregation means that small packets are merged into a larger packet. It can change the packet-length sequence even when the application behavior is similar.

### contrastive learning

Contrastive learning trains a model by pulling related samples closer and pushing unrelated samples apart. In TAC-Seq, two perturbed views of the same flow are treated as related samples.

### augmented view

An augmented view is a modified version of the original sample. In TAC-Seq, each view is generated by applying TCP-aware perturbations to the same packet-length sequence.

### positive pair

A positive pair means two views that come from the same original flow. TAC-Seq trains the model to keep their representations close.

### negative sample

A negative sample means a view from a different flow. TAC-Seq trains the model to separate it from the positive pair.

### NT-Xent loss

NT-Xent loss is the contrastive loss used in the SimCLR-style framework. Its role is to pull positive pairs closer and push negative samples apart using normalized representations, similarity, and a temperature parameter.

### BiLSTM-Attention

BiLSTM-Attention is the sequence encoder used in my undergraduate thesis. BiLSTM captures packet-order context, and attention helps the model focus on more informative packet positions.

### projection head

A projection head maps the encoder output into the contrastive learning space during pretraining. After pretraining, it is removed and the encoder is used for classification.

### supervised classifier

A supervised classifier is the final classifier trained with labels after contrastive pretraining. In my undergraduate thesis, it predicted the TLS application category.

### Macro-F1

Macro-F1 is the average F1 score across classes, treating each class equally. It is useful when we care about performance on smaller or harder classes.

### Weighted-F1

Weighted-F1 is the average F1 score weighted by the number of samples in each class. It reflects overall performance while considering class imbalance.

### Rosetta-style baseline

A Rosetta-style baseline means a reproduced baseline inspired by Rosetta, which uses TCP-aware traffic augmentation for robust TLS traffic classification. I used it as a stronger comparison target than a simple linear baseline.

### RTO setting

An RTO setting means a perturbation setting related to retransmission timeout behavior. In my experiments, TAC-Seq showed strong robustness under this setting.

### Nagle-like aggregation

Nagle-like aggregation means a heuristic simulation of small-packet aggregation behavior. I used it because the dataset did not provide timestamps for modeling the real Nagle algorithm directly.

### CESNET-TLS22

CESNET-TLS22 is the TLS traffic dataset used in my undergraduate thesis. I used it to build an eight-class encrypted traffic classification task.
